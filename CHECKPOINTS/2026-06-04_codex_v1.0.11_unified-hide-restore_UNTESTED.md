## Scope

Architectural refactor for a single pocketed item state pipeline across local host, singleplayer, client ACK, host-hosted client pocket, remote observers, room property replay, late join, cleanup, death/level transitions, and player-left cleanup.

No publish, no push, no Thunderstore release.

## Pre-edit diagnosis

- Invisible collision was caused by divergent hide paths and incomplete enforcement. Some paths hid renderers/map marker but did not keep all child colliders, trigger colliders, rigidbody collision flags, damage behaviours, audio, and markers disabled locally on every client.
- Host-pocketed items still affected Player 2 because Photon does not synchronize component enabled states such as Collider.enabled, Rigidbody.detectCollisions, AudioSource, SpriteRenderer, or gameplay behaviours. Every client must apply the pocketed state locally.
- Saw/serra damage likely came from trigger/hurt colliders and own update behaviours. v1.0.10 logs showed the saw had audio spam and reflection showed IceSawValuable/HurtCollider/ValuableSawBlade-style components. Saw/Blade/Hazard items are temporarily blocked as SpecialItemBlocked in v1.0.11.
- Yellow TAB/minimap markers persisted for observers because marker hiding lived in owner/local helper paths, while HideRemoteItem/RoomProperties/late-join observer paths did not consistently hide MapValuable marker state locally.
- "Can not play a disabled audio source" spam came from disabling AudioSource while game behaviours kept calling Play(). v1.0.11 stops audio, keeps the source enabled, mutes it, sets volume to zero, and disables likely controller behaviours while hidden.
- Player 2 timeout risk came from pending request dictionaries that only tracked nonce/viewID/timestamp and did not consistently clear on denial, timeout, death, level change, destroyed items, or player-left cleanup.

## Main changes

- Added centralized PocketOperations.HidePocketedItemState and RestorePocketedItemState with HideMode/RestoreMode.
- Snapshot now captures full hierarchy state for colliders, renderers, line renderers, trails, particles, lights, audio mute/volume/enabled/playing, MapValuable marker renderer, layers, rigidbody state, PhysGrabObject, and suppressible behaviours.
- Hidden state now disables all colliders/triggers, sets Rigidbody.isKinematic=true and detectCollisions=false, disables interaction and damage/audio/marker/effect behaviours, hides marker locally, stops/clears effects, and mutes audio without disabling AudioSource.
- Restore state uses snapshot when available; remote restore without finalPos uses safe defaults and skips stale marker restore.
- EnforcePocketState now reapplies the centralized hidden state for local, hosted, owner-ACK, and remote observer state.
- Pending requests now track nonce, viewID, timestamp, actor, type, and state; timeout/cleanup paths clear pending HUD/request state.
- Host pocket/drop handling now explicitly denies invalid, destroyed, level-changing, full, blocked, or already-hosted cases where possible.
- Internal version updated to v1.0.11 in BepInPlugin, startup log, and project version.

## Temporarily blocked

- Saw/Blade/Hazard-style items and items with dangerous components such as IceSaw, SawBlade, ValuableSaw, HurtCollider, or Hazard are blocked as SpecialItemBlocked until they can be supported safely.
