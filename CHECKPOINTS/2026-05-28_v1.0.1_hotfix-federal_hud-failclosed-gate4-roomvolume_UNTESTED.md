## 1. Motivação — Por que o hotfix anterior foi insuficiente

### Bug A (HUD no loading) — causa raiz real

Log confirmou:
```
[81] HandleLevelChange disparado → _isTransitioningOrLoading=true, _inGameplay=false
[85] PocketManager.Awake() disparado DURANTE O LOADING SCREEN
     → _inGameplay=true, _isTransitioningOrLoading=false   ← OVERRIDE fatal
[94] Nível carregado
```

**Causa:** No REPO, PlayerAvatar é destruído e recriado em cada troca de fase.
`PocketManager.Awake()` disparava durante o loading e sobrescrevia os flags de transição
definidos por `HandleLevelChange()` instantes antes. A janela de loading ficava com
`_inGameplay=true` e `_isTransitioningOrLoading=false` → HUD visível.

O timer de 8s do hotfix anterior era insuficiente porque o override de Awake()
ocorria imediatamente (< 1s após HandleLevelChange).

### Bug B (GATE4 falso-positivo) — causa raiz real

Log confirmou blocker dominante: `Extra (3) (layer:RoomVolume)`

**Causa:** O REPO usa a layer "RoomVolume" para volumes que preenchem salas inteiras
(colisores sólidos, não-triggers). `Physics.OverlapSphereNonAlloc` com
`Physics.DefaultRaycastLayers` incluía essa layer. Em praticamente toda tentativa de drop,
o esfera de verificação GATE4 colidia com o volume da sala → SphereFull → bloqueio.

## 2. Hotfix Federal aplicado

### Parte A — HUD sistema fail-closed

**Filosofia:** Awake() = componente existe. **NÃO** = gameplay renderizável.
HUD só abre quando `RunIsLevel()` confirma explicitamente.

#### Campos novos (substituem o sistema antigo)

| Campo | Valor default | Descrição |
|---|---|---|
| `_hasLocalPocketManager` | `false` | Awake() foi chamado (componente existe) |
| `_hudGameplayReady` | `false` | RunIsLevel() confirmou nível ativo em Update() |
| `_hudSuppressedForTransition` | `true` | Fail-closed: suprime HUD até confirmação |
| `_cachedRunIsLevel` | `false` | Cache de TrySemiRunIsLevel() atualizado em Update() |
| `_layerRoomVolume` | `-1` | Lazy init de LayerMask.NameToLayer("RoomVolume") |

#### Campos removidos (sistema antigo)

- `_inGameplay`
- `_isTransitioningOrLoading`
- `_levelTransitionTime`
- `LEVEL_TRANSITION_SETTLE_SECS`
- `_lastHudHiddenReason`

#### Mudanças por método

| Método | Mudança |
|---|---|
| `Awake()` | Só seta `_hasLocalPocketManager=true; _hudSuppressedForTransition=true`. SEM liberar HUD. |
| `Update()` | Cache `RunIsLevel()` → `_cachedRunIsLevel`. Se `_hudSuppressedForTransition && _cachedRunIsLevel`: clear supressão, seta ready. |
| `ShouldRenderHud()` | Lê apenas campos cacheados. Sem reflexão, sem mutação de estado. |
| `HandleLevelChange()` | Seta `_hudGameplayReady=false; _hudSuppressedForTransition=true` |
| `ClearAllState()` | Seta `_hudGameplayReady=false; _hudSuppressedForTransition=true` |

#### Fluxo de estados do HUD

```
Default / inicial:
  _hasLocalPocketManager=false → ShouldRenderHud=false

Awake() (pode ser durante loading):
  _hasLocalPocketManager=true, _hudSuppressedForTransition=true
  → ShouldRenderHud=false (suprimido) ✓

HandleLevelChange() chamado:
  _hudGameplayReady=false, _hudSuppressedForTransition=true
  → ShouldRenderHud=false ✓

Awake() re-dispara durante loading (avatar recriado):
  _hudSuppressedForTransition=true (já estava, mantém)
  → ShouldRenderHud=false ✓

RunIsLevel()=false (ainda loading):
  _cachedRunIsLevel=false
  → Condição Update() não satisfeita → sem mudança → ShouldRenderHud=false ✓

Nível carregado, RunIsLevel()=true:
  _cachedRunIsLevel=true
  → Condição: _hudSuppressedForTransition && _cachedRunIsLevel = true && true
  → _hudSuppressedForTransition=false; _hudGameplayReady=true
  → ShouldRenderHud=true ✓

ClearAllState() (menu/OnLeftRoom):
  _hudGameplayReady=false, _hudSuppressedForTransition=true
  → ShouldRenderHud=false ✓
  → Update() não libera (RunIsLevel()=false no menu) ✓
```

### Parte B — GATE4 filtro RoomVolume

#### Mudanças em `IsDropSphereClear()`

Nova assinatura:
```csharp
private static bool IsDropSphereClear(
    Vector3 center, float radius, int mask,
    PlayerAvatar player, GameObject grabbedGo, out string blockerName)
```

Filtros adicionados (em ordem):
1. **RoomVolume layer** — `LayerMask.NameToLayer("RoomVolume")` — volumes de sala do REPO
2. **PlayerAvatar local** — `col.transform.IsChildOf(player.transform)` (existia antes)
3. **Item segurado** — `col.transform.IsChildOf(grabbedGo.transform)` (novo)

Novo formato de log GATE4:
```
[QP:SafeDrop] ang=0 gate=GATE4 result=FAIL reason=SphereFull blocker=NAME layer=LAYER path=ROOT/CHILD
```

Helpers adicionados:
- `BuildShortPath(Transform t)` — retorna `"Root/Child"` para log
- `EnsureLayersInitialized()` — lazy init de `_layerRoomVolume`

#### Mudança em `TryFindSafeDropPosition()`

Adicionado no início:
```csharp
var grabbedPgo = SemiFunc.PhysGrabberLocalGetGrabbedPhysGrabObject();
var grabbedGo  = (grabbedPgo != null) ? grabbedPgo.gameObject : null;
```
