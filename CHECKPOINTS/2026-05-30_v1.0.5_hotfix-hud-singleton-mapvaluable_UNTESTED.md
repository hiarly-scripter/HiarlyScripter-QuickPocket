## Diagnóstico — causas confirmadas via log e reflection

### A — HUD no loading (causa real encontrada)
**Causa principal:** nenhum guard `if (this != Instance) return;` em `Update()` e `OnGUI()`.
- PlayerAvatar é destruído/recriado entre fases
- PocketManager antigo (stale, com `_hudGameplayReady=true`) continua rodando `Update()` e `OnGUI()` até ser destruído junto com o PlayerAvatar antigo
- Janela entre nova fase (novo Instance) e destruição do antigo = HUD aparece porque stale.OnGUI() não tinha guard

**Causa secundária:** `LoadingUI.levelAnimationCompleted` não era verificado — RunIsLevel() pode retornar true antes da animação de loading completar visualmente.

### B — Marker TAB persiste (causa real encontrada via reflection)
**Causa real:** `MapValuable` é um objeto SEPARADO na hierarquia do Map system — NÃO é filho do item. `GetComponentsInChildren<Behaviour>` no item nunca o encontra. Abordagem anterior (v1.0.4) filtrava Behaviours locais ao item, por isso nunca funcionou para o marker.

**Solução:** `Object.FindObjectsOfType<MapValuable>()` com filtro `mv.target == valuableObject` encontra o marker correto. Desativar via `gameObject.SetActive(false)`.

```csharp
if (this != Instance) return;  // PRIMEIRA LINHA
```


**Core.cs — `Awake()`:**

- Sempre reseta `_runIsLevelTrueStreak = 0`

**Resultado:** Stale PocketManager é silenciado IMEDIATAMENTE quando novo Awake() seta Instance, mesmo antes do PlayerAvatar antigo ser destruído.

### Fix 2 — LoadingUI kill-switch direto

**Core.cs — novo campo:**
```csharp
private bool _cachedIsLoading = true;  // fail-closed por default
```

**Core.cs — Update():** `_cachedIsLoading = IsLoadingActive();`

**Core.cs — ShouldRenderHud():** `if (_cachedIsLoading) return false;`

**Core.cs — IsLoadingActive():**
```csharp
private static bool IsLoadingActive()
{
    var lui = LoadingUI.instance;  // singleton da tela de loading
    if (lui == null) return false;
    // levelAnimationCompleted é campo privado → AccessTools (cached)
    // false = loading em andamento; true = animação completada
    bool animDone = (bool)_loadingUIAnimCompleted.GetValue(lui);
    return !animDone;
}
```

`LoadingUI` é o singleton nativo do REPO que controla a tela de loading.  
`levelAnimationCompleted` muda de `false` para `true` quando a animação de loading termina.

### Fix 3 — MapValuable: ponto dourado TAB some ao pocketar

**Por que abordagem anterior falhou:** `GetComponentsInChildren<Behaviour>` busca no item. `MapValuable` não é filho do item — está na hierarquia do Map system.

**Eligibility.cs — novo campo em ComponentSnapshot:**
```csharp
public MapValuable MapValuableMarker;  // objeto separado no Map system
```

**PocketOperations.cs — SaveSnapshot:**
```csharp
// Encontrar MapValuable que aponta para o ValuableObject deste item
foreach (var mv in UnityEngine.Object.FindObjectsOfType<MapValuable>())
    if (mv.target == valuableObj) { snap.MapValuableMarker = mv; break; }
```
Log: `[QP:MapMarker] item=X method=MapValuable markerFound=True/False`

**PocketOperations.cs — ApplyHide:**
```csharp
if (snap.MapValuableMarker != null)
    snap.MapValuableMarker.gameObject.SetActive(false);
```
Log: `[QP:MapMarker] item=X disabled=True`

**PocketOperations.cs — RestoreSnapshot:**
```csharp
if (snap.MapValuableMarker != null)
    snap.MapValuableMarker.gameObject.SetActive(true);
```
Log: `[QP:MapMarker] item=X restore=True`
