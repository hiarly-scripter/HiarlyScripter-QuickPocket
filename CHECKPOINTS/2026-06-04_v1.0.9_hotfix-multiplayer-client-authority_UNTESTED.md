# Checkpoint — QuickPocket v1.0.9
# Hotfix: Multiplayer Client Pocket Authority (Host-Authoritative)
# Data: 2026-06-04 | Status: UNTESTED

## Causa Raiz Confirmada

No REPO, todos os itens têm `OwnershipTransfer=Fixed` owned pelo master.
Player 2 (`actor=2, isMine=false, isMaster=false`) tentava `ApplyHide` localmente.
O master override via Photon sync (~50ms) desfazia kinematic/components → item voltava ao estado original.
`IsPocketStateConsistent` detectava inconsistência → enforcement loop → `key not found` → removido → HUD 0/5.

## Arquitetura Implementada

### Modelo: Host-Authoritative via RaiseEvent

Todos os itens Fixed são operados pelo master em nome do cliente.
Cliente atualiza HUD/localPocket SOMENTE após ACK do master.

### Event Codes

| Code | Direção | Descrição |
|------|---------|-----------|
| 71 (EV_REQUEST_POCKET) | Client → Master | Solicitar pocket |
| 72 (EV_ACK_POCKET)     | Master → Client | Pocket aprovado |
| 73 (EV_DENY_POCKET)    | Master → Client | Pocket negado |
| 74 (EV_REQUEST_DROP)   | Client → Master | Solicitar drop |
| 75 (EV_ACK_DROP)       | Master → Client | Drop aprovado + posição |
| 76 (EV_DENY_DROP)      | Master → Client | Drop negado |

Sync para outros clientes: Room Properties `QP_{actor}` já existentes → `OnRoomPropertiesUpdate` → `HideRemoteItem`.

### Fluxo Pocket (não-master)

```
Client: H pressionado → EV_REQUEST_POCKET(vid, nonce, item) → Master
         HUD: "Aguarde..."
Master: valida (exists, notAlreadyPocketed, limitOK)
        → SaveSnapshot + ApplyHide (master é owner → persiste via Photon)
        → _hostedPockets[actor].Add((vid, snap))
        → Room Properties QP_{actor} = [vid...] (outros clientes veem)
        → EV_ACK_POCKET(vid, nonce, item) → Client
Client: recebe ACK → _localPocket.Add(vid) + _clientHostedItems.Add(vid)
        HUD: "Guardado: X (1/5)"
```

### Fluxo Drop (não-master)

```
Client: H pressionado → EV_REQUEST_DROP(vid, nonce) → Master
         HUD: "Aguarde..."
Master: localiza snap em _hostedPockets[actor]
        → GetPositionByActorNumber(actor) + Vector3.up*0.5
        → RestoreSnapshot(go, snap, dropPos)
        → _hostedPockets[actor].Remove(vid)
        → Room Properties QP_{actor} atualizado
        → EV_ACK_DROP(vid, nonce, item, px, py, pz) → Client
Client: recebe ACK → _localPocket.Remove(vid) + _clientHostedItems.Remove(vid)
        HUD: "Retirado: X (0/5)"
```

### Host (isMaster=true, isMine=true)

Unchanged: pocket direto (SaveSnapshot + ApplyHide + _localPocket + _snapshots + PublishPocketedItems).

### Singleplayer

Unchanged: pocket direto sem eventos.
