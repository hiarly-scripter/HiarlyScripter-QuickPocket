## Host flow

When the host pockets an item, the local hide pipeline applies the full pocketed state and hides the MapValuable marker locally. Remote clients receive the pocketed state and also hide their local marker representation.

When the host observes Player 2 pocketing an item, v1.0.12 ensures the host processes the remote addition path enough to reapply the host-side MapValuable hide without performing duplicate remote restore on drop.

## Player 2 flow

Player 2 pockets and drops through the request/ACK path. The owner side hides local visuals and marker on ACK, while the host manages the authoritative hosted pocket state and publishes room properties for observers.
